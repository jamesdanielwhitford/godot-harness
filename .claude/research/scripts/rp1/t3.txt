Build the game flow for a small 2D game: main menu (Play, Quit) -> level 1 -> level 2 -> game over screen (reached when the player dies or touches a hazard) -> retry restarts from level 1. Each level is a simple scene with a player that can move, a hazard, and an exit to the next level. Scene changes must use fade transitions (fade to black and back). The main menu is the main scene.
