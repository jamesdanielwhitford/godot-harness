# R1.4 Godot 4.7 .tscn/.tres format, UIDs, safe scene writing

All [Run] results come from the Godot 4.7.stable.official.5b4e0cb0f editor binary (Linux, headless) on 2026-10-15. Source cites are to `godotengine/godot` tag `4.7-stable` (shallow clone). Test project and all case files: `r1_4_work/proj/` (cases in `proj/cases/`, raw run output in `r1_4_work/cases_out.txt`). Tool scripts: `r1_4_work/tools/`.

## Answer

1. Never hand-write a whole scene when you can generate it. Hand edits fail silently far more often than they fail loudly (table below). Silent failures: unknown property, wrong-typed value, duplicate ids, duplicate sibling names, node-ref export without `node_paths`, UID that resolves to a different file than the path.
2. Safest path for creation: a `--script` (SceneTree) generator that builds nodes with `ClassDB.instantiate`, `add_child(n, true)`, sets `owner = root` on every node, then `PackedScene.pack()` and `ResourceSaver.save()`. Tested skeleton below ([Run] exit 0, output re-loads cleanly).
3. Safest path for modification: `load(path).instantiate(PackedScene.GEN_EDIT_STATE_MAIN)` (or `_MAIN_INHERITED` for inherited scenes), edit, pack, save. The default `instantiate()` (DISABLED) flattens inherited and instanced overrides and destroys inheritance. [Run] below.
4. Always follow any edit with a load-check that captures engine errors AND warnings (`OS.add_logger` + `Logger` subclass, works in 4.7 [Run]; the version that introduced it was not checked). `load()` returning non-null does not mean the file is right: in my runs 10 broken cases loaded with exit 0 and no log output at all. A digest/diff of the semantic content is the second gate.
5. In 4.7 the header is `[gd_scene format=3]` (usually) with optional `uid`; `load_steps` is deprecated and ignorable; node `unique_id=` is new in 4.6 and optional. A `uid` on a scene is optional: scripts saved outside the editor get no uid and everything still works by path.
6. Moving files outside the editor: scripts get `.uid` sidecars (generated by `--headless --import`); if the `.uid` moves with its file, scenes referencing the old path still resolve via UID without being rewritten. If the `.uid` is lost and the file's content changed, the scene's uid dangles and only the text path saves you (warning). Neither `--import` nor `--editor --quit` rewrites scene files. [Run]

## 1. File format facts

| Topic | Fact | Evidence |
|---|---|---|
| Header | `[gd_scene format=3 uid="uid://..."]`; `uid` optional; `load_steps` deprecated since 4.6, "should be ignored if present" | [Doc: https://docs.godotengine.org/en/stable/engine_details/file_formats/tscn.html#file-structure] ; [Run] c21 (`load_steps=99` plus bogus uid) loads fine |
| format number | Source defines `FORMAT_VERSION = 4`, `FORMAT_VERSION_COMPAT = 3`. Writer emits 3 unless a PackedByteArray over 64 bytes or any PackedVector4Array is stored, then 4. Loader rejects `format` greater than 4 ("Saved with newer format version") | [Src: godot@4.7-stable:scene/resources/resource_format_text.h:46-48]; [Src: resource_format_text.cpp:1736-1743, 1810, 1153]; [Run] `item_small.tres` format=3, `item_blob.tres` (100-byte blob) format=4; c19 `format=5` -> load fails. The docs page says "format=3 in Godot 4.x", which is incomplete. |
| format missing / 2 | Loads. `[gd_scene]` with no format loads; Godot 3 `format=2` file with `ExtResource( 1 )` integer ids loads | [Run] c20, c22 |
| Node `unique_id` | Added in 4.6, optional, regenerated randomly on first engine re-save of a hand-written scene (noisy diffs). Duplicate values in one file load silently | [Doc tscn page "Note that unique_id is only present in scenes saved with Godot 4.6 or later"]; [Run] d05, `scene_gen` output |
| Section order | ext_resource, sub_resource, node, connection, editable. Sub-resources must be defined before use (forward ref = hard load error). The engine writer reorders ext_resource entries by first use | [Doc: "referring resource must appear before the reference"]; [Run] c08; out2 diff shows reorder |
| ext_resource id | Any string, not just `N_xxxxx`; may equal a sub_resource id (separate namespaces). Duplicate ext ids: last wins silently. Duplicate sub ids: FIRST wins, second block's properties silently ignored | [Run] d01, c06, c07; [Src: resource_format_text.cpp:622-628 cache hit sets `do_assign=false`] |
| Engine rewrites ids | After any engine re-save, ids become `<n>_<5 random chars>` and are re-ordered. Do not depend on ids across saves | [Run] complex_out2 diff |
| ext_resource uid | Optional. Valid uid wins over path; unknown uid falls back to the text path with a warning; no path at all is a hard error | [Src: resource_format_text.cpp:491-505]; [Run] c04, c05, d03, d08 |
| node `parent=` | Root has no `parent`. Direct children use `"."`; deeper use `"A/B"` relative to root, NEVER including the root name. A bad parent is a warning at instantiate, and that node (and its subtree) is dropped | [Doc]; [Run] c10, c11 -> `WARNING: Parent path './Root/A' ... has vanished` |
| Node order | Parent must appear before child (child-before-parent = vanished-parent warning). A second node without `parent` = hard error at instantiate | [Run] c12, c13 |
| Duplicate sibling names | Loads silently with two nodes named the same | [Run] d06 -> `["A:Node2D", "A:Sprite2D"]` |
| Instances | `[node name="A" parent="." instance=ExtResource("id")]` (no `type`). Overrides of inner nodes: `[node name="Sprite" parent="A" index="0"]` plus props (no `type`). New node under an inner node: `[node name="Extra" type="Marker2D" parent="A/Inner"]` (engine writes extra `parent_id_path=PackedInt32Array(...)`, new in 4.6, optional on load) | [Run] complex.tscn / ov.tscn |
| Inherited scene | Root is `[node name="X" instance=ExtResource("base")]` (no type, no parent); inherited children are overrides with `parent="." index="N"` | [Run] inh.tscn |
| `[editable path="A"]` | Not needed to LOAD overrides (d04 override applied). It IS needed for the engine to SAVE overrides of nodes inside instance A: without it a re-pack silently drops them | [Run] d04: after `instantiate(MAIN)` + pack, Sprite override lost, no editable line; [Src: scene/resources/packed_scene.cpp:799 skips nodes owned by a non-editable instance] |
| `[connection]` | `[connection signal="x" from="A/Sprite" to="." method="_m" flags=3 binds=[..]]`. Bad node = silently ignored or error; bad signal name = ERROR log but scene still loads; the `to="Ghost"` (nonexistent target) line produced no log line in my run. `flags` 2 = CONNECT_PERSIST (what editor-made connections have), engine always ORs it in on save | [Run] c17, digest flags=2/3 |
| Node-typed exports | Stored as `NodePath(...)` and listed in `node_paths=PackedStringArray("prop")` on the node header. If `node_paths` is missing the property loads as null, silently | [Run] c25 (target set) vs c26 (target null); generator output shows `node_paths` auto-written |
| Value syntax | Standard Variant text: `Vector2(1, 2)`, `Color(...)`, `NodePath("../A:pos")`, `&"stringname"`, `ExtResource("id")`, `SubResource("id")`, `Array[int]([1, 2])`, `Dictionary[String, int]({...})`, packed arrays. Typed array/dict syntax round-trips | [Run] c24 loads and re-reads `Array[int]([1, 2, 3])` |
| Default values | Properties equal to default are omitted by the writer; writing them by hand is legal but discarded on re-save | [Doc] |
| Comments/whitespace | `;` comments and extra whitespace are legal, discarded on re-save | [Doc]; [Run] d07 |
| .tres | `[gd_resource type="Resource" script_class="ItemData" format=3]`, then `[resource]` block with `script = ExtResource(...)`; `script_class` is the `class_name` | [Run] `cases/item_small.tres` |
| Scene UID on disk | `.tscn/.tres` carry their uid in the header (no `.uid` sidecar). Scripts and other non-text-format files get `<file>.uid` sidecars. A scene saved from a plain `--script` run has NO uid and gets none from `--import` or `--headless --editor --quit` | [Src: core/io/resource_loader.cpp:1428-1440 `should_create_uid_file`]; [Run] header of main.tscn stayed `[gd_scene format=3]` after both |
| Why scripts save no uid | The id lookup callback `ResourceSaver::set_get_resource_id_for_path` is installed only by EditorFileSystem (editor GUI session), so ext_resource lines written from a SceneTree script also carry no `uid=` | [Src: editor/file_system/editor_file_system.cpp:3805]; [Run] main.tscn ext_resource has no uid |
| Giving a scene a uid from a script | `ResourceSaver.set_uid(path, ResourceUID.create_id_for_path(path))` rewrites the header; a subsequent `--import` registers it and `load("uid://...")` works. Before the import: `Unrecognized UID` error | [Run] tools/setuid.gd; tools/uidload.gd |
| UID generation is deterministic | `create_id_for_path` seeds an RNG from project name x lowercase path x file MD5. A regenerated `.uid` for unchanged content at the same path gets the same uid; any content or path change gives a new uid | [Src: core/io/resource_uid.cpp:134-155]; [Run] T4: deleted `.godot` and `hero.gd.uid`, reimport -> same `uid://dvpey5akgbony` |
| UID duplicates | Two files with the same uid: `WARNING: UID duplicate detected between ...` at import, ambiguity resolved arbitrarily | [Run] T7 (copied .gd + .uid) |

## 3. Rules an agent must follow (<= 20)

1. Prefer the generator (below) for new scenes and the `GEN_EDIT_STATE_MAIN` round-trip for edits to engine-written scenes; hand-edit .tscn only for tiny surgical changes (one property, one node), then run the load-check and the digest.
2. Header: write `[gd_scene format=3]` (no `load_steps`; omit `uid` for new scenes, never invent one; copy an existing one when editing). Use `format=4` only if the engine wrote it.
3. Order: ext_resources, sub_resources (dependencies first), nodes (parents before children, root first), connections, editable.
4. Root node: no `parent`. Direct children `parent="."`. Deeper `parent="A/B"`, never including the root name.
5. Sibling names must be unique. Check explicitly; the engine will not.
6. Every `ExtResource("x")` / `SubResource("x")` needs a declaration with that exact id earlier in the file. Ids must be unique per kind. Do not renumber ids by hand.
7. ext_resource needs `type`, `path`, `id`; `uid` optional. If you include a uid it must be the real one from `<script>.uid` or the scene header, otherwise omit it (a wrong uid gives a warning, a UID pointing to a different file silently wins over the path).
8. Property names and value types must match the engine's property exactly; the engine drops unknown names silently. Validate against `ClassDB.class_get_property_list` (generator does) or run the digest with `--all-props` and diff.
9. Object-typed exports (Node references) need both `node_paths=PackedStringArray("prop")` on the node header and `prop = NodePath("...")`; otherwise they load as null.
10. Instanced node: no `type`. Overrides of inner nodes: `parent="A"` plus the property lines, plus `[editable path="A"]` at the end of the file. New nodes under an inner node: give `type` and `parent="A/Inner"`.
11. Scripts: `script = ExtResource("id")` with an ext_resource of `type="Script"`. The `.gd` file must exist first.
12. In GDScript generators every node that must be saved needs `owner = root`, set after `add_child`. Never set owner on children inside an instanced scene. Use `add_child(n, true)`; unnamed nodes otherwise get names like `@Node2D@2`.
13. For edits via the engine always use `instantiate(PackedScene.GEN_EDIT_STATE_MAIN)` (or `_MAIN_INHERITED` for scenes whose root is an instance/inherits); never plain `instantiate()`.
14. `PackedScene.pack()` and `ResourceSaver.save()` return OK for structurally lossy results; compare node counts/digest before and after.
15. After the engine saves, ids and `unique_id` values are regenerated and connections reordered. Expect diff noise; commit after normalising once (round-trip hand-written scenes through the engine) rather than mixing styles.
16. Run `godot --headless --path . --import` after cloning and after any add/move/delete of files. It generates missing `.uid` sidecars and refreshes the uid cache. Commit the `.uid` files.
17. Move/rename with the `.uid` sidecar attached (`git mv x.gd x.gd.uid`). Moving a script via `mv` + `--import` keeps scenes working via UID without rewriting them; renaming without the `.uid` orphans references. Text paths in scenes are then stale but harmless, update them with a script/sed if you want clean diffs.
18. Never edit `.godot/`, never commit it, never hand-edit `.import` files.
19. After any change to .tscn/.tres: run `load_check.gd` on the changed files and on their dependents (scenes that instance them). Treat exit 1 and 3 as failure.
20. Treat a Godot-3-style file, `format=2` or `ExtResource( 1 )` syntax, in an LLM edit as a bug even though the loader tolerates it.

## 5. Generator and digest skeletons (tested)

Spec format: `{"save","root":{name,type|instance,script,props,groups,unique_name,children},"overrides":{"A/Sprite":{prop:val}},"extra_nodes":[{"parent":"A/Inner",...node}],"connections":[{from,signal,to,method,flags}]}`. Property values: JSON scalars are converted to the property's type; `{"$var":"Vector2(1,2)"}` goes through `str_to_var`; `{"$res":"res://x.png"}` loads a resource; `{"$node":"Path"}` sets a node reference (written with `node_paths`). Not supported yet: sub_resources are supported only via `$res` of an existing .tres or by building the resource in code; array-of-node exports; signals binds/unbinds.

Run: `godot --headless --path <proj> --script /abs/tools/scene_gen.gd -- /abs/spec.json` (exit 0 ok, 2 spec/IO, 3 build error, 4 save error). Digest: `... --script scene_digest.gd -- res://scenes/x.tscn [--all-props]` (exit 1 if load fails). Check: `... --script load_check.gd -- res://a.tscn res://b.tres`.

Sample digest output (complex.tscn):
```
scene res://scenes/complex.tscn uid=uid://<invalid> nodes=6
  . : Node2D  {script=res://scripts/hero.gd}
  ./A : (instance)  [instance res://scenes/child.tscn]  {position, speed}
  ./A/Sprite : (override of inherited/instanced node)  {position}
  ./A/Inner/Extra : Marker2D  {position}
  ./Area : Area2D  {groups=["zone"]}
  ./Area/Shape : CollisionShape2D  {shape}
  connect A.hit -> .._on_hit flags=2
  connect Area.area_entered -> .._on_hit flags=3
  deps: ["res://scenes/child.tscn", "res://scripts/hero.gd"]
```
Known digest limits: it reads the PackedScene state only, so `%UniqueName` nodes defined inside instanced scenes are not listed (they are listed for the scene that declares them), and instance-internal nodes show only if overridden.

### scene_gen.gd
```gdscript
extends SceneTree
## Usage: godot --headless --path <proj> --script scene_gen.gd -- spec.json
## Spec (JSON):
## {"save":"res://scenes/a.tscn",
##  "root":{"name":"Main","type":"Node2D","script":"res://scripts/hero.gd",
##          "props":{"position":{"$var":"Vector2(10,20)"},"texture":{"$res":"res://icon.svg"},"target":{"$node":"Child"}},
##          "groups":["g"],"unique_name":false,
##          "children":[{...same shape..., or "instance":"res://scenes/other.tscn"}]},
##  "connections":[{"from":"Child","signal":"hit","to":".","method":"_on_hit","flags":0}]}
## Exit code: 0 ok, 2 spec/IO error, 3 node creation error, 4 save error.
var errors: PackedStringArray = []
var pending_refs: Array = []   # [node, prop, path] resolved after tree is built

func _init() -> void:
	var args := OS.get_cmdline_user_args()
	if args.size() < 1:
		_fail(2, "usage: -- spec.json")
		return
	var txt := FileAccess.get_file_as_string(args[0])
	var spec = JSON.parse_string(txt)
	if typeof(spec) != TYPE_DICTIONARY:
		_fail(2, "bad JSON spec: " + args[0])
		return
	var root := _build(spec["root"], null, null)
	if root == null:
		_fail(3, "build failed:\n" + "\n".join(errors))
		return
	for r in pending_refs:
		var n: Node = root.get_node_or_null(NodePath(r[2]))
		if n == null:
			errors.append("node ref not found: %s (for %s.%s)" % [r[2], r[0].name, r[1]])
		else:
			r[0].set(r[1], n)
	# Overrides of properties on nodes INSIDE instanced scenes (needs set_editable_instance or pack() drops them).
	for path in spec.get("overrides", {}):
		var tgt := root.get_node_or_null(NodePath(path))
		if tgt == null:
			errors.append("override target not found: " + path); continue
		var anc := tgt
		while anc != null and anc != root:
			if anc != tgt and anc.scene_file_path != "": root.set_editable_instance(anc, true)
			anc = anc.get_parent()
		for k in spec["overrides"][path]:
			tgt.set(k, _val(spec["overrides"][path][k], tgt, k))
	# New nodes added UNDER nodes of an instanced scene.
	for ex in spec.get("extra_nodes", []):
		var par := root.get_node_or_null(NodePath(ex["parent"]))
		if par == null: errors.append("extra_nodes parent not found: " + str(ex["parent"])); continue
		var a2 := par
		while a2 != null and a2 != root:
			if a2 != par and a2.scene_file_path != "": root.set_editable_instance(a2, true)
			a2 = a2.get_parent()
		if _build(ex, par, root) == null: break
	for c in spec.get("connections", []):
		var f := root.get_node_or_null(NodePath(c["from"]))
		var t := root.get_node_or_null(NodePath(c["to"]))
		if f == null or t == null or not f.has_signal(c["signal"]) or not t.has_method(c["method"]):
			errors.append("bad connection: %s" % [c])
			continue
		f.connect(c["signal"], Callable(t, c["method"]), int(c.get("flags", CONNECT_PERSIST)) | CONNECT_PERSIST)
	if not errors.is_empty():
		_fail(3, "\n".join(errors))
		return
	var ps := PackedScene.new()
	var err := ps.pack(root)
	if err != OK:
		_fail(4, "pack failed: %s" % error_string(err))
		return
	err = ResourceSaver.save(ps, spec["save"])
	if err != OK:
		_fail(4, "save failed: %s" % error_string(err))
		return
	print("OK saved ", spec["save"], " nodes=", _count(root))
	root.free()
	quit(0)

func _val(v, n: Node, k: String):
	if typeof(v) == TYPE_DICTIONARY:
		if v.has("$var"): v = str_to_var(v["$var"])
		elif v.has("$res"): v = load(v["$res"])
	for p in n.get_property_list():
		if p["name"] == k and typeof(v) != p["type"] and p["type"] != TYPE_NIL and p["type"] != TYPE_OBJECT:
			return type_convert(v, p["type"])
	return v

func _count(n: Node) -> int:
	var c := 1
	for ch in n.get_children(): c += _count(ch)
	return c

func _fail(code: int, msg: String) -> void:
	printerr("scene_gen ERROR: ", msg)
	quit(code)

func _build(d: Dictionary, parent: Node, root: Node) -> Node:
	var n: Node
	if d.has("instance"):
		var ps = load(d["instance"])
		if ps == null or not (ps is PackedScene):
			errors.append("cannot load instance " + str(d["instance"])); return null
		n = ps.instantiate(PackedScene.GEN_EDIT_STATE_INSTANCE)  # keeps it an instance link
	else:
		if not ClassDB.class_exists(d.get("type", "")) or not ClassDB.can_instantiate(d["type"]):
			errors.append("unknown/abstract type " + str(d.get("type"))); return null
		n = ClassDB.instantiate(d["type"])
	n.name = d["name"] if d.has("name") else n.name
	if d.has("script"):
		var s = load(d["script"])
		if s == null: errors.append("cannot load script " + d["script"])
		else: n.set_script(s)
	var r := root if root != null else n
	if parent != null:
		parent.add_child(n, true)
		n.owner = r        # THE OWNER RULE: every node to be saved needs owner = scene root
	# NOTE: children *inside* an instanced scene must not be re-owned (we never recurse into them).
	var plist := {}
	for p in n.get_property_list(): plist[p["name"]] = p
	for k in d.get("props", {}):
		var v = d["props"][k]
		if typeof(v) == TYPE_DICTIONARY and v.has("$node"):
			pending_refs.append([n, k, v["$node"]]); continue
		v = _val(v, n, k)
		if not plist.has(k) and not (k.contains("/") or k.contains(":")):
			errors.append("%s has no property '%s'" % [n.name, k]); continue
		if plist.has(k) and typeof(v) != plist[k]["type"] and plist[k]["type"] != TYPE_NIL and plist[k]["type"] != TYPE_OBJECT:
			v = type_convert(v, plist[k]["type"])
		n.set(k, v)
	for g in d.get("groups", []): n.add_to_group(g, true)
	if d.get("unique_name", false): n.unique_name_in_owner = true
	for ch in d.get("children", []):
		if _build(ch, n, r) == null: return null
	return n
```

### scene_digest.gd
```gdscript
extends SceneTree
## Usage: godot --headless --path <proj> --script scene_digest.gd -- res://scenes/a.tscn [--all-props]
## Prints tree / types / scripts / unique names / groups / connections / ext deps. Exit 0 ok, 1 load failure.
func _init() -> void:
	var args := OS.get_cmdline_user_args()
	if args.is_empty(): printerr("usage: -- res://x.tscn"); quit(2); return
	var path: String = args[0]
	var res = ResourceLoader.load(path, "", ResourceLoader.CACHE_MODE_IGNORE)
	if res == null or not (res is PackedScene):
		printerr("DIGEST FAIL: cannot load ", path); quit(1); return
	var st: SceneState = res.get_state()
	print("scene ", path, " uid=", ResourceUID.id_to_text(ResourceLoader.get_resource_uid(path)), " nodes=", st.get_node_count())
	for i in st.get_node_count():
		var np := st.get_node_path(i)
		var ntype := String(st.get_node_type(i))
		var inst := st.get_node_instance(i)
		if ntype == "": ntype = "(instance)" if inst != null else "(override of inherited/instanced node)"
		var line := "  " + ("." if i == 0 else str(np)) + " : " + ntype
		if inst != null: line += "  [instance " + inst.resource_path + "]"
		var extra := []
		var gr := st.get_node_groups(i)
		if gr.size() > 0: extra.append("groups=" + str(gr))
		for j in st.get_node_property_count(i):
			var pn := st.get_node_property_name(i, j)
			var pv = st.get_node_property_value(i, j)
			if pn == "script" and pv is Script: extra.append("script=" + pv.resource_path)
			elif pn == "unique_name_in_owner" and pv: extra.append("%unique")
			elif "--all-props" in args: extra.append(pn + "=" + var_to_str(pv))
			else: extra.append(pn)
		if not extra.is_empty(): line += "  {" + ", ".join(extra) + "}"
		print(line)
	for i in st.get_connection_count():
		print("  connect ", st.get_connection_source(i), ".", st.get_connection_signal(i), " -> ",
			st.get_connection_target(i), ".", st.get_connection_method(i), " flags=", st.get_connection_flags(i))
	var deps := ResourceLoader.get_dependencies(path)
	print("  deps: ", deps)
	quit(0)
```

### load_check.gd
```gdscript
extends SceneTree
## Usage: godot --headless --path <proj> --script load_check.gd -- res://a.tscn [res://b.tres ...]
## Loads (cache ignored) + instantiates each file, capturing every engine ERROR/WARNING via OS.add_logger.
## Exit 0 = clean; 1 = load/instantiate failure; 3 = loaded but engine emitted errors/warnings.
class Cap extends Logger:
	var msgs: PackedStringArray = []
	func _log_error(function: String, file: String, line: int, code: String, rationale: String, editor_notify: bool, error_type: int, script_backtraces: Array) -> void:
		var kind := "WARNING" if error_type == ERROR_TYPE_WARNING else "ERROR"
		msgs.append("%s: %s" % [kind, rationale if rationale != "" else code])
func _init() -> void:
	var cap := Cap.new()
	OS.add_logger(cap)
	var rc := 0
	for p in OS.get_cmdline_user_args():
		var before := cap.msgs.size()
		var res = ResourceLoader.load(p, "", ResourceLoader.CACHE_MODE_IGNORE)
		if res == null:
			print("FAIL load ", p); rc = 1
		else:
			var detail := ""
			if res is PackedScene:
				var inst = res.instantiate()
				if inst == null: print("FAIL instantiate ", p); rc = 1
				else:
					detail = " root=%s children=%d" % [inst.get_class(), inst.get_child_count()]
					inst.free()
			print("loaded ", p, detail)
		for i in range(before, cap.msgs.size()):
			print("  ", cap.msgs[i])
		if cap.msgs.size() > before and rc == 0: rc = 3
	OS.remove_logger(cap)
	quit(rc)
```
