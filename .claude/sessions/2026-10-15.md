## Key findings (details in the reports)
- Godot exit codes cannot be trusted for checks; grep output and use `timeout`. A fresh clone needs `--import`.
- A headless editor serves GDScript LSP (`--headless --editor --lsp-port 6005`): a strong analyser hook (untested beyond a type-error probe).
- Many broken `.tscn` cases load silently with exit 0; need a log-capturing load-check. Generate scenes with the engine (`scene_gen.gd`), keep owner/editable-instance rules.
- Godot 3 `.tscn` and syntax load or get remapped silently in 4.7; lint rules (1,213 in `r1_5_lint/lint_rules_full.yaml`) catch them.
- gdUnit4 recommended; GUT exit codes unsafe. C# via gdUnit4Net works on 4.7 mono for trivial tests; plain `dotnet test` works only for Godot-free libraries.
- Screenshots: Xvfb + gl_compatibility; repeatable byte-for-byte on same binary/renderer with `--fixed-fps` and seeds. `--headless` cannot screenshot.
- Determinism is strong on one machine (physics 2D/3D and Jolt); idle-mode Tween/Timer/AnimationPlayer are not. Cross-machine is untested.
- No official Godot MCP server. Best fit for an optional live layer: `beremaran/godot-agent-loop`; borrow `satelliteoflove/godot-mcp` stepping design. Core harness stays a CLI one-shot design.
- Talks: simulation as pure code, one state snapshot, commands in, events out, view as dumb choreographer.
